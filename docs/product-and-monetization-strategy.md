# 개간단컷 제품·수익화 전략

> 상태: 출시 정책으로 채택  
> 결정일: 2026-08-22  
> 현재 내부 프로젝트명: SimpleCut  
> 출시 예정 제품명: 개간단컷

## 1. 결정 요약

개간단컷은 **영구 무료 기본판 + 사용자가 직접 시작하는 7일 Pro 체험 + 1회 구매 Pro 평생 이용권**으로 출시한다.

- 광고를 넣지 않는다.
- 핵심 편집 기능에 구독제를 적용하지 않는다.
- 회원 가입과 자체 서버를 필수로 만들지 않는다.
- 무료판과 체험판에도 워터마크를 넣지 않는다.
- 체험 기간이 끝나도 프로젝트와 원본을 삭제하거나 열지 못하게 하지 않는다.
- iPhone·iPad·Mac에서 하나의 Pro 구매 권한을 공유하는 것을 목표로 한다.
- 서버 비용이 실제로 발생하는 AI·클라우드 기능만 향후 별도 과금 대상으로 검토한다.

이 정책은 단기 광고 매출보다 제품 신뢰, 유료 전환, 개인 개발자의 유지 가능성을 함께 최적화하기 위한 결정이다.

## 2. 목표 사용자와 해결할 문제

### 주요 사용자

- 사진 앱의 영상과 사진을 빠르게 이어 붙이려는 개인 사용자
- 음성 메모와 음악을 영상에 간단히 추가하려는 사용자
- CapCut 같은 대형 편집기의 복잡한 화면, 계정, 광고, 구독이 부담스러운 사용자
- 전문 편집기까지는 필요 없지만 결과물의 화질과 프로젝트 복원은 포기하고 싶지 않은 사용자
- iPhone에서 시작해 iPad 또는 Mac에서 이어서 편집하려는 Apple 기기 사용자

### 핵심 약속

> 광고도 구독도 없이, 사진과 음성 메모로 바로 만드는 내 영상.  
> 한 번 구매하면 iPhone, iPad, Mac에서 계속 사용합니다.

## 3. 상품 구성

### 무료 기본판

무료판도 처음부터 끝까지 실제 영상을 완성할 수 있어야 한다.

- 컷 분할, 삭제, 순서 이동
- 기본 트림, 크롭, 회전과 화면 맞춤
- 기본 텍스트와 음악
- 이미지, 영상, M4A 음성 파일 추가
- 메인 트랙과 오버레이 1개
- 1080p 30fps 내보내기
- 프로젝트 개수와 영상 길이 제한 없음
- 워터마크, 광고, 계정 요구 없음

프로젝트 수나 영상 길이를 제한해 사용자 데이터를 인질처럼 만들지 않는다. 무료와 Pro는 저장 데이터가 아니라 고급 기능, 출력 사양, 작업 효율로 구분한다.

### Pro 평생 이용권

- 무제한 영상, 오디오, 텍스트, 오버레이 레이어
- 4K, 60fps, HDR 내보내기
- 마스크, 모자이크, 이미지 배경 제거
- 고급 크롭, 키프레임과 애니메이션
- 고급 글꼴, 글자 스타일, 필터, 테두리와 그림자
- 그룹 편집, 길이 맞춤, 고급 타임라인 도구
- 프로젝트 패키지 저장과 기기 간 이동
- iCloud Drive 기반 프로젝트 동기화
- 고급 자막과 오디오 편집
- 가능한 경우 백그라운드 내보내기와 우선 처리
- iPhone, iPad, Mac 공통 구매 권한

Pro 기능 목록은 실제 구현과 안정성 검증이 완료된 기능만 스토어에 표시한다.

### 7일 Pro 체험

- 앱 설치와 동시에 시작하지 않는다.
- 사용자가 처음 Pro 기능을 선택하거나 고급 출력 옵션을 선택했을 때 체험 시작을 제안한다.
- 시작 전에 체험 기간, 제공 기능, 종료 후 상태와 자동 결제가 없다는 점을 설명한다.
- 사용자가 명시적으로 `7일 무료 체험 시작`을 눌러야 시작한다.
- 체험 중에는 Pro 전체 기능과 워터마크 없는 내보내기를 제공한다.
- 체험 종료 후에는 무료 기본판으로 돌아간다.
- 프로젝트는 계속 열고 편집할 수 있으며 사용 중인 Pro 기능을 정확히 표시한다.
- 체험 종료를 이유로 프로젝트나 원본 미디어를 삭제하지 않는다.

비구독 체험은 App Store의 가격 0 비소모성 인앱결제로 구현하고, 평생 이용권은 별도의 유료 비소모성 인앱결제로 구현한다. `구매 복원` 기능을 항상 제공한다.

## 4. 가격 정책

가격은 제품 완성도와 지원 기기 범위에 따라 단계적으로 조정한다.

| 단계 | 조건 | 권장 가격 |
| --- | --- | ---: |
| 초기 구매자 | Mac 중심, 핵심 안정성은 확보했지만 모바일 공통판 이전 | 19,000~24,000원 |
| 공통판 출시 | iPhone·iPad·Mac 구매 권한과 프로젝트 호환 제공 | 29,000원 |
| 정상 가격 | 충분한 실제 사용자 검증, 안정적 복원·내보내기 확보 | 39,000원 |
| 고급판 수준 | 고급 합성·자막·오디오·효과까지 안정적으로 제공 | 45,000~49,000원 |

- 출시 기념 가격은 기간과 종료일을 미리 알리고 한 번만 사용한다.
- 반복적인 반값 할인으로 정가의 신뢰를 훼손하지 않는다.
- 초기 구매자가 이미 구매한 로컬 Pro 기능을 나중에 다시 구독 기능으로 바꾸지 않는다.
- 가격 인상은 신규 구매자에게만 적용하고 기존 구매 권한은 유지한다.

## 5. 채택하지 않는 수익 모델

### 광고 기반 무료 앱

출시 모델로 채택하지 않는다.

- 배너가 작은 iPhone 편집 공간을 차지한다.
- 전면 광고가 편집과 내보내기의 집중 흐름을 끊는다.
- 광고 SDK가 개인정보 고지, 동의 관리, 네트워크 오류와 앱 충돌 가능성을 추가한다.
- 영상 편집은 게임처럼 광고를 반복 노출하기 어려워 작은 사용자 규모에서는 수익 효율이 낮다.
- `광고와 추적 없는 개인 편집기`라는 가장 분명한 차별점을 잃는다.

### 핵심 기능 구독제

출시 모델로 채택하지 않는다.

- 로컬 편집 기능은 매달 서버 비용이 발생하지 않는다.
- 개인 영상 편집은 사용 주기가 불규칙해 월 구독과 맞지 않는다.
- 지속적인 신규 콘텐츠와 서비스를 제공하지 못하면 구독의 정당성이 약하다.
- CapCut, VLLO, InShot과 같은 대형 서비스의 콘텐츠 규모와 직접 경쟁하게 된다.

### 처음부터 유료 다운로드

출시 모델로 채택하지 않는다.

- 알려지지 않은 신규 앱이 품질을 증명하기 전에 결제를 요구하게 된다.
- 무료 경쟁 앱이 많은 시장에서 다운로드 전환이 지나치게 낮아질 수 있다.
- 체험과 무료 기본판을 통한 자연스러운 추천이 어렵다.

## 6. 향후 유료 기능 원칙

### 기기 내에서 실행되는 기능

Apple Vision이나 기기 내 모델처럼 실행할 때마다 외부 비용이 들지 않는 기능은 가능한 한 Pro 평생 이용권에 포함한다.

### 서버 비용이 발생하는 AI 기능

다음 순서로 과금 방식을 검토한다.

1. 사용량에 비례하는 소모성 AI 크레딧
2. 대량 사용자를 위한 선택적 AI 패스
3. 클라우드 저장 공간과 지속적인 콘텐츠가 함께 제공될 때만 선택적 구독

AI 또는 클라우드 구독을 추가하더라도 기존 Pro의 로컬 편집 기능을 제거하거나 구독 뒤로 옮기지 않는다.

## 7. 경쟁 전략

개간단컷은 효과와 템플릿 개수로 CapCut과 경쟁하지 않는다. 아래 경험을 더 잘 제공하는 데 집중한다.

1. **로컬 우선과 개인정보 보호**
   - 원본 영상과 사진을 자체 서버에 올리지 않는다.
   - 계정 없이 바로 시작한다.
   - 광고 추적 SDK를 넣지 않는다.

2. **Apple 기기 특화**
   - 사진 앱, 파일 앱, 음성 메모 공유에서 바로 추가한다.
   - HEVC, HDR, M4A 등 Apple 기기에서 흔한 형식을 우선 검증한다.
   - 동일한 프로젝트 형식을 iPhone, iPad, Mac에서 사용한다.

3. **복원을 믿을 수 있는 편집기**
   - 앱 종료, 뒤로 가기, 기기 재시작 이후에도 원본 연결과 편집 상태를 복원한다.
   - 원본 누락 시 검정 화면만 표시하지 않고 누락 파일과 복구 방법을 알려준다.
   - 자동 저장은 원자적으로 처리하고 이전 정상 세대도 복구할 수 있게 한다.

4. **기능을 찾을 필요가 없는 화면**
   - 현재 선택한 요소와 상황에 필요한 기능만 보여준다.
   - iPhone에서는 엄지손가락이 닿는 위치에 주요 동작을 배치한다.
   - 고급 기능은 숨기지 않되 상세 패널과 `더보기`로 단계적으로 공개한다.

5. **귀엽지만 작업을 방해하지 않는 브랜드**
   - 강아지 얼굴 로고와 간결한 안내 문구로 친근함을 만든다.
   - 캐릭터는 로딩, 빈 화면, 도움말에 제한적으로 사용한다.
   - 편집 화면 자체는 정돈되고 전문적인 도구의 밀도를 유지한다.

## 8. 출시 전에 충족해야 할 기준

결제 기능보다 아래 핵심 품질을 먼저 완성한다.

- HEVC, H.264, HDR, M4A와 일반 이미지 형식 가져오기 검증
- 긴 영상과 4K 영상에서 미리보기 메모리 사용량 관리
- 결과 MP4의 실제 재생 가능 여부 자동 검사
- 내보내기 실패 시 원인과 해결 방법을 사용자가 이해할 수 있게 표시
- 앱 종료, 창 닫기, 강제 종료 후 프로젝트·미디어 복원 검증
- 저장 공간 부족, 원본 이동, iCloud 다운로드 대기 상태 처리
- 구매, 체험, 만료, 환불, 구매 복원과 오프라인 실행 검증
- VoiceOver, 충분한 터치 영역과 키보드 조작 검증
- 무료 기능만 사용한 프로젝트와 Pro 기능이 섞인 프로젝트의 만료 후 동작 검증

## 9. 출시 단계

1. `개간단컷` 이름, 상표 가능성, 판매자 계정 형태와 Bundle ID 확정
2. 강아지 얼굴 로고와 앱 아이콘, 디자인 토큰 확정
3. 공통 프로젝트 형식과 원본 미디어 보관 정책 확정
4. iPhone·iPad용 네이티브 편집·내보내기 기반 구현
5. 무료판과 Pro 기능 경계를 실제 UI와 내보내기에 적용
6. 7일 체험, 평생 이용권, 구매 복원 구현
7. 실제 기기와 TestFlight에서 편집·복원·내보내기 검증
8. 초기 구매자 가격으로 출시
9. 안정성, 유료 전환과 환불 데이터를 확인한 뒤 정상 가격으로 조정

## 10. 측정할 지표

자체 추적 서버 없이 가능한 App Store 지표와 사용자가 동의한 최소한의 진단만 사용한다.

- 다운로드 후 첫 프로젝트 생성 비율
- 첫 프로젝트 생성 후 첫 정상 내보내기 성공 비율
- 내보내기 성공률과 형식별 실패 원인
- Pro 기능 진입 대비 체험 시작 비율
- 7일 체험 대비 평생 이용권 구매 비율
- 환불률과 구매 복원 실패율
- 프로젝트 복원 실패와 원본 누락률
- 기기별 충돌 없는 사용 비율

초기에는 매출 자체보다 `첫 정상 내보내기`, `복원 성공`, `유료 전환` 세 지표를 우선한다. 편집 결과를 신뢰할 수 없는 상태에서 광고나 결제 화면을 최적화하지 않는다.

## 11. 정책 변경 조건

아래 조건이 실제 데이터로 확인될 때만 수익 모델을 다시 검토한다.

- 광고: 무료 활성 사용자가 매우 커지고도 편집 경험과 개인정보 약속을 훼손하지 않는 광고 형식이 확인된 경우
- 구독: 매월 새로운 유료 콘텐츠를 공급하거나 클라우드·AI 서버 비용이 지속적으로 발생하는 경우
- AI 크레딧: 서버 추론 비용이 사용자별 사용량에 따라 유의미하게 발생하는 경우
- 별도 차세대 앱: 기존 앱과 호환하기 어려운 대규모 엔진 교체와 장기간의 새 개발이 필요한 경우

조건이 충족되지 않으면 **무료 기본판 + 7일 Pro 체험 + Pro 평생 이용권** 정책을 유지한다.
