# 이미지 편집 처리 기준

## 로컬 AI 배경 제거

- 기존 방식은 이미지 테두리에서 우세한 한 가지 색을 찾는 알고리즘이어서 복잡한 배경,
  머리카락, 피사체가 테두리에 닿는 사진을 제대로 이해할 수 없었다.
- 현재 기본 방식은 Apache-2.0 라이선스의 `onnx-community/ormbg-ONNX` 양자화 모델과
  MIT 라이선스의 ONNX Runtime Web을 사용한다.
- 모델 추론과 알파 합성은 별도 Web Worker에서 실행해 편집 화면을 멈추지 않는다.
- 모델 파일은 첫 사용 때만 공식 Hugging Face 저장소에서 받고 Cache Storage에 보관한다.
  사진 파일과 픽셀은 네트워크로 전송하지 않는다.
- 같은 사진의 민감도를 바꿀 때는 이미 계산한 신뢰도 마스크를 재사용한다.
- 네트워크, WebAssembly, 메모리 문제로 AI를 실행할 수 없으면 기존 연결 색상 알고리즘을
  사용해 기능 전체가 실패하지 않게 한다.

## 영역 모자이크

- 영역은 원본 미디어 기준의 상대 좌표로 저장하므로 캔버스 해상도와 화면 크기가 바뀌어도
  같은 위치를 가린다.
- 한 항목에 최대 12개 영역을 추가할 수 있고 각 영역의 위치, 너비, 높이, 픽셀 크기를 저장한다.
- 팝업 편집창, 일반 미리보기, 자동저장·프로젝트 파일, FFmpeg 내보내기가 같은 데이터를 쓴다.
- 내보내기는 FFmpeg의 `crop` + `pixelize` + `overlay` 필터를 사용하며 전체 화면을 흐리는 대신
  지정한 영역만 비파괴적으로 픽셀화한다.
